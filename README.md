# DeepClean Pro (ديب كلين برو) - الإصدار 2.0

**DeepClean Pro** هو أداة متطورة وشاملة لصيانة نظام التشغيل Windows، تم تصميمها لتحسين أداء النظام، تنظيف الملفات المؤقتة، وحماية الخصوصية، بالإضافة إلى مراقبة صحة الأقراص الصلبة. البرنامج يوفر واجهة مستخدم رسومية سهلة الاستخدام مع ميزات قوية للمستخدمين المتقدمين.

---

## 🚀 المميزات الرئيسية

### 1. تنظيف النظام العميق (System Cleanup)
يقوم البرنامج بفحص وتنظيف مجموعة واسعة من الملفات التي تستهلك مساحة القرص وتبطئ النظام:
- **الملفات المؤقتة (Temp Files):** تنظيف مجلدات Temp الخاصة بالمستخدم والنظام.
- **ذاكرة التخزين المؤقت (Prefetch):** تحسين سرعة تشغيل النظام عبر تنظيف ملفات التخزين المسبق القديمة.
- **تحديثات ويندوز (Windows Update):** إفراغ ذاكرة التخزين المؤقت لتحديثات Windows لتوفير مساحة كبيرة.
- **سجلات النظام (System Logs):** مسح سجلات الأحداث (Event Logs) وملفات `.log` المتراكمة.
- **سلة المحذوفات (Recycle Bin):** إفراغ سلة المحذوفات لقرص النظام بشكل آمن.
- **تقارير الأخطاء (Crash Dumps):** حذف ملفات تفريغ الذاكرة الناتجة عن انهيار البرامج.
- **ذاكرة DNS:** تنظيف ذاكرة التخزين المؤقت لـ DNS لتحسين مشاكل الاتصال.

### 2. تنظيف التطبيقات والمتصفحات
- **المتصفحات المدعومة:** Chrome, Edge, Brave, Opera, Firefox (تنظيف الكاش والملفات المؤقتة).
- **التطبيقات:** Discord, Slack, Spotify, Steam.
- **الوصول السريع (Quick Access):** مسح قائمة الملفات الأخيرة والوصول السريع Jump Lists.

### 3. صيانة الويندوز المتقدمة
- **أداة DISM:** تشغيل تنظيف مكونات صورة النظام (Component Cleanup) لتقليل حجم مجلد WinSxS.
- **أداة تنظيف القرص (Cleanmgr):** تكامل مع أداة ويندوز الرسمية بتشغيل تلقائي متقدم.
- **تنظيف السجل (Registry):** مسح سجلات الاستخدام الأخيرة (MRUs) وتاريخ تشغيل البرامج لتعزيز الخصوصية.

### 4. فحص صحة القرص (Disk Health & Benchmark)
- **معلومات القرص:** عرض الموديل، النوع (SSD/HDD)، والحالة الصحية العامة.
- **درجة الحرارة:** مراقبة درجة حرارة الأقراص في الوقت الفعلي.
- **اختبار الأداء:** قياس سرعة القراءة والكتابة التسلسلية للقرص.
- **تقارير مفصلة:** عرض أخطاء القراءة والكتابة وحالة الأقسام (Volumes).

## 🛡️ الأمان والموثوقية
- **نقطة استعادة النظام:** يقوم البرنامج تلقائياً بإنشاء "System Restore Point" قبل البدء بعملية التنظيف لضمان إمكانية العودة في حال حدوث أي مشكلة.
- **وضع المحاكاة (Simulation Mode):** يتيح لك رؤية ما سيقوم البرنامج بحذفه دون إجراء أي تغييرات فعلية على الملفات.

---

## 💻 المتطلبات التقنية
- **نظام التشغيل:** Windows 10 أو Windows 11 (64-bit).
- **الإطار البرمجي:** .NET 8.0 Runtime.
- **الصلاحيات:** يتطلب تشغيل البرنامج بصلاحيات المسؤول (Administrator) للوصول إلى ملفات النظام والسجل.

---

## 🛠️ كيفية الاستخدام
1. قم بتحميل البرنامج وتثبيته عبر ملف `setup`.
2. قم بتشغيل البرنامج كمسؤول.
3. اختر العناصر التي ترغب في تنظيفها من القائمة الجانبية.
4. (اختياري) فعل "وضع المحاكاة" للتجربة.
5. اضغط على **"Start Deep Cleanup"** لبدء العملية.
6. اذهب إلى تبويب **"Disk Health"** للحصول على تقرير مفصل عن حالة الهارد ديسك لديك.
